# BLLManage

BLLManage é uma API REST desenvolvida em ASP.NET Core utilizando Clean Architecture, DDD e boas práticas de desenvolvimento.

O projeto está sendo construído como um estudo completo de arquitetura backend, simulando um ambiente real de desenvolvimento.

## Tecnologias

- .NET 8
- ASP.NET Core
- C#
- Entity Framework Core
- PostgreSQL
- Docker
- xUnit
- Swagger

## Arquitetura

```
BLLManage
│
├── BLLManage.Api
├── BLLManage.Application
├── BLLManage.Domain
├── BLLManage.Infrastructure
└── BLLManage.Tests
```

## Funcionalidades implementadas

- Estrutura Clean Architecture
- Entidade Company
- Validação de domínio
- Testes unitários
- Endpoint para criação de empresas
- Injeção de Dependência

## Em desenvolvimento

- Entity Framework Core
- PostgreSQL
- Docker
- JWT Authentication
- Refresh Token
- Redis
- GitHub Actions

## Objetivo

Este projeto foi criado para representar uma aplicação profissional, utilizando conceitos encontrados em projetos reais do mercado.
